## 🪙 Thai Coin Detection

**Mini Project — AI & Computer Vision**

โปรเจกต์ตรวจจับเหรียญไทยแบบ Real-time โดยใช้ **YOLOv5, PyTorch และ Flask** สามารถตรวจจับเหรียญผ่านกล้อง Webcam พร้อมระบุประเภทเหรียญ ได้แก่ **10, 5, 2, 1 และ 0.50 บาท** และคำนวณมูลค่ารวมของเหรียญที่ตรวจพบโดยอัตโนมัติ

### 🔧 Technologies

* Python
* YOLOv5
* PyTorch
* OpenCV
* Flask
* HTML / CSS
* Computer Vision

### ✨ Features

* ตรวจจับเหรียญแบบ Real-time ผ่าน Webcam
* จำแนกประเภทเหรียญไทย
* คำนวณยอดรวมของเหรียญอัตโนมัติ
* ใช้ Data Augmentation เพื่อเพิ่มความหลากหลายของ Dataset
* แสดงผลการตรวจจับผ่าน Web Application

### 🎯 Objective

พัฒนาความรู้ด้าน **Computer Vision, Object Detection และ AI Model Deployment** ผ่านการสร้างระบบตรวจจับเหรียญที่สามารถใช้งานบน Web Application ได้จริง
